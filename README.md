# 🤖 Dify Daily Assistant (全能个人助手)

这是一个基于 **Dify** 框架搭建的全能私人助手，旨在处理日常生活和工作中的各类任务。

该智能体集成了大语言模型、工作流编排、外部插件与 MCP 工具，能够应对极其丰富的场景：需要生成图片/视频、出门前规划路线、获取饮食推荐、或是进行复杂的数据分析与图表生成时，都能游刃有余。

---

## ✨ 核心功能模块

本项目涵盖以下功能模块：

- 💬 **日常生活问答**：解答日常生活中的一般性问题，提供实用建议。
- ✍️ **文案润色优化**：对用户的原始文本进行语言修饰与逻辑优化。
- 🎨 **多模态内容生成**：集成文生图、文生视频模型（如豆包 Seedream 系列）。
- 📊 **数据查询与可视化分析**：通过代码节点或数据库查询数据，并生成分析图表。
- 🗺️ **MCP 工具集成**：连接外部 MCP 服务（如高德地图、饮食推荐、新闻资讯等），实现实时数据交互。

---

## 🚀 快速开始 (How to use)

如果你想在你的 Dify 环境中运行这个助手，请按照以下步骤操作：

### 1. 导入工作流
1. 克隆或下载本仓库的 `.yml` 文件。
2. 登录你的 Dify 控制台，进入 **"工作室" (Studio)**。
3. 点击 **"导入 DSL 文件"**，选择刚刚下载的 `.yml` 文件。

### 2. 配置 API 密钥
导入后，由于安全原因，部分插件与模型需要重新授权：
- 配置你使用的大语言模型（如 OpenAI、DeepSeek、豆包等）的 API Key。
- 配置相关插件（如 AntV 图表、即梦 AIGC 等）所需的密钥或访问凭证。

### 3. 运行测试
配置完成后，进入该应用，输入 `帮我生成视频：一个漂亮的亚洲网红美女手拿着一束鲜花站在街头` 或 `帮我分析商品` 即可测试多模态生成与数据分析功能。
